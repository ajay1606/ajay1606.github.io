WeZON: Autonomous On-Demand EV Charging as a Service

A compact autonomous mobile robot that brings EV charging directly to parked vehicles using a low-cost sensor suite, autonomous navigation, mobile energy storage, and an app-driven charging workflow.

Ajay Kumar and collaborators

Project Overview

WeZON explores a new model for on-demand EV charging as a service using an Autonomous Mobile Robot (AMR). Instead of requiring every electric vehicle to move to a dedicated charging stall, the charging resource itself can autonomously travel to the parked vehicle.

The project integrates a compact mobile robotic platform, onboard energy storage, a low-cost LiDAR and camera sensing suite, localization, obstacle-aware navigation, path planning, and an application interface for requesting and monitoring charging services.

A primary objective of the project is to develop a deploy-ready autonomous navigation module that can operate in parking environments while maintaining reasonable system cost and hardware complexity. The complete use case was demonstrated in a campus parking environment in coordination with the University of Minnesota Parking and Transportation Services.

Why Mobile EV Charging?

Conventional EV charging infrastructure is largely based on fixed charging locations. This model can introduce challenges related to installation cost, dedicated parking-space requirements, charging availability, equipment utilization, waiting time, and deployment in locations where permanent charging infrastructure is difficult to install.

Growing EV adoption increases demand for flexible charging infrastructure while conventional fixed chargers remain constrained by installation, availability, space, and operational requirements.

Representative charging challenges across rural, urban, harsh-weather, campus, and fixed-parking environments.

Key Contributions

On-Demand Charging

Charging is delivered directly to the parked vehicle, reducing dependence on dedicated EV charging stalls.

Low-Cost Sensor Suite

The platform integrates RGB vision, 2D LiDAR, onboard computing, and wheel-based mobility while targeting a practical prototype cost.

Autonomous Navigation

Localization, camera–LiDAR perception, obstacle detection, and path planning allow the robot to navigate autonomously through parking environments.

Integrated User Service

A mobile application connects user requests, parking-location selection, payment, robot dispatch, charging monitoring, and service completion.

Real-World Demonstration

The complete concept was demonstrated using a physical AMR platform in a University of Minnesota campus parking environment.

End-to-End System Workflow

WeZON connects the user application, backend service, autonomous robot, navigation system, and mobile charging hardware into a unified service workflow.

1

User Request

The user selects a parking location and requests EV charging through the mobile application.

2

Backend Matching

The system receives the request and assigns an available mobile charging robot.

3

Robot Dispatch

The AMR receives the target parking location and autonomously navigates toward the requested vehicle.

4

Charging Service

The onboard energy-storage system provides charging power while the session is monitored.

5

Completion

Charging and payment are completed and the robot becomes available for another service request.

Complete WeZON service pipeline from user request and backend matching to robot navigation, EV charging, completion, and payment.

Low-Cost Hardware Platform

The prototype was designed around commercially available components to support rapid deployment and reduce system cost. The platform combines sensing, onboard computation, mobile energy storage, and a robotic chassis within a compact AMR configuration.

Prototype hardware target: less than approximately $10K, combining the mobile chassis, LiDAR, RGB camera, onboard computing, power station, brackets, and charging cabling.

Core prototype hardware including SICK picoScan150 LiDAR, RGB camera, NVIDIA Jetson Orin AGX, Anker SOLIX F3800 power station, Agile-X chassis, and associated charging hardware.

Autonomous Navigation and Functional Modules

A key focus of WeZON is developing an autonomous navigation stack that can operate reliably in parking facilities using a relatively compact sensing configuration.

The system combines camera and 2D LiDAR fusion for detecting vehicles and surrounding obstacles, localization for maintaining accurate robot position, and map-based path planning for reaching the requested charging location.

Camera + LiDAR Fusion

Visual object detection is associated with 2D LiDAR measurements to provide semantic and geometric information about surrounding vehicles and obstacles.

Accurate Localization

LiDAR-based localization improves robot positioning and helps reduce lateral drift during parking-lot navigation.

Precise Path Planning

Occupancy information is used to generate safe, obstacle-aware paths toward the requested charging location.

Key autonomous-navigation functions supported by the SICK picoScan LiDAR: camera–LiDAR fusion, localization, and precise path planning.

User App and Charging-Service Interaction

The mobile application provides the user-facing interface for requesting WeZON charging service. The workflow supports parking-lot selection, charger availability, reservation, authentication, payment, arrival confirmation, robot dispatch, charging-status monitoring, and service completion.

App-based charging workflow from parking-lot selection and reservation through payment, robot dispatch, charging progress, and completion.

Potential Deployment Scenarios

The same mobile charging concept can support environments where vehicles remain parked for extended periods or where deployment of large numbers of fixed chargers may be difficult or inefficient.

University Campuses

Mobile charging can serve faculty, staff, students, campus fleets, and shared vehicles without reserving every parking space for fixed chargers.

Airports

Long-term parking environments provide an opportunity for charging robots to service parked vehicles during extended dwell times.

Retail and Shopping Centers

Mobile charging can expand EV charging availability without requiring extensive conversion of general parking spaces.

Carshare and Fleet Services

On-demand mobile energy delivery can support high-utilization shared and fleet vehicles.

Potential deployment scenarios include university campuses, airports, shopping centers, and carshare or fleet services.

Prototype Demonstration

The WeZON prototype demonstrates the integration of a deployable autonomous-navigation system with an energy-delivery platform for on-demand EV charging. Testing focuses on robot navigation through parking environments, vehicle perception, localization, path planning, and delivery of the charging service at the requested vehicle location.

Behavior-Driven Motion Modeling for Intelligent Autonomous Navigation

Semantic-aware perception and risk-aware motion planning for autonomous mobile robots operating in human-shared indoor environments.

Ajay Kumar, Tejas Chavan, Rushikesh Zende, Kalyan Sai, Zhi-Li Zhang

Abstract

This work presents a behavior-driven motion modeling framework for autonomous indoor robot navigation in environments shared with pedestrians and static obstacles. Using onboard LiDAR and camera sensing, the robot distinguishes between human and non-human obstacles and adapts its motion profile accordingly to support safer and more context-aware navigation.

The system integrates LiDAR map-matching and wheel odometry for localization, camera-based perception and LiDAR-camera fusion for environmental understanding, and semantic grounding to associate detected objects with navigation risk. An occupancy-map-based DSP planner then generates collision-free trajectories and adjusts the robot's speed according to object type and environmental constraints.

Experiments were conducted using a fully autonomous mobile robot equipped with LiDAR, RGB cameras, IMU sensors, and onboard NVIDIA Jetson Orin computing. The system was evaluated across pedestrian-shared corridors, narrow passages, static obstacles, and dynamic interaction scenarios, demonstrating adaptive and smooth autonomous navigation in challenging indoor environments.

Key Contributions

Multimodal Localization

LiDAR map matching combined with wheel odometry enables robust indoor localization in GPS-denied environments.

Semantic Perception

Camera perception and LiDAR-camera association distinguish pedestrians, static obstacles, furniture, and other objects.

Risk-Aware Planning

Semantic object information is converted into occupancy weights and navigation risk scores for trajectory planning.

Adaptive Robot Motion

The robot adapts trajectory, linear velocity, and angular velocity according to pedestrians and environmental constraints.

Autonomous Mobile Robot Platform

The experimental platform is equipped with a 16-channel LiDAR, multiple RGB cameras, an IMU, wheel encoders, and an NVIDIA Jetson Orin for onboard perception, planning, and control.

AMR experimental platform integrating LiDAR, RGB cameras, IMU, wheel odometry, onboard display, and NVIDIA Jetson Orin computing.

System Architecture

1. Localization

LiDAR map matching is combined with wheel odometry to estimate the robot pose and motion continuously.

2. Perception

RGB cameras support real-time object detection and semantic scene understanding.

3. Sensor Fusion

Camera detections are associated with LiDAR measurements to obtain spatially grounded object information.

4. Planning

Semantic information and occupancy risk are incorporated into the DSP planner to generate safe robot trajectories.

Autonomous Navigation in Shared Indoor Environments

The robot was evaluated in representative indoor navigation scenarios involving pedestrians, narrow passages, and static obstacles. The navigation system dynamically modifies the trajectory and motion profile according to the surrounding environment.

Representative navigation scenarios including pedestrian following, pedestrian passing, narrow passages, and static obstacle avoidance.

Perception Pipeline

The perception module combines RGB imagery and LiDAR point clouds to detect objects, assign semantic information, and associate visual observations with 3D spatial measurements.

Multimodal perception pipeline combining RGB imagery, real-time object detection, semantic grounding, LiDAR measurements, and fused spatial perception.

LiDAR-Camera Sensor Fusion

Camera-based detections provide semantic object information, while the LiDAR point cloud provides accurate spatial measurements. Their association allows the navigation system to determine both what an obstacle is and where it is located.

Association of 2D camera detections with 3D LiDAR observations for spatially grounded obstacle perception.

Semantic Awareness

Real-time object detection identifies navigation-relevant entities, while semantic grounding provides additional contextual understanding of the surrounding indoor scene. This allows pedestrians and environmental obstacles to be treated differently during planning.

Semantic perception pipeline using object detection and scene-level semantic understanding to differentiate humans, furniture, structural elements, and other objects.

Risk-Aware Occupancy Planning

The 3D occupancy representation is augmented with semantic risk information. Higher navigation penalties are assigned to safety-critical regions, particularly those associated with pedestrians and dynamic obstacles.

Occupancy-map generation, semantic risk-score assignment, and DSP-based trajectory generation.

Behavior-Driven Motion Profile

Object-dependent occupancy weights influence both path selection and robot motion. Pedestrians receive higher navigation risk than static environmental structures, encouraging greater clearance and reduced speed during human-robot interaction.

Example semantic risk weighting and resulting changes to planned trajectory, linear velocity, and angular velocity.
